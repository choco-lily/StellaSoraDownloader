# 스텔라 소라 다운로더

여러 서버에서 스텔라 소라 게임 파일을 다운로드할 수 있는 고급 비교 및 선택 기능을 갖춘 종합 GUI 애플리케이션입니다.

## 주요 기능

### 🌐 다중 서버 지원
- 여러 스텔라 소라 서버 지원 (KR, EN, JP, CN)
- 실시간 서버 상태 확인
- 서버별 파일 크기 및 해시 비교

### 📁 고급 파일 관리
- **파일 선택**: 체크박스를 사용한 특정 파일 다운로드 선택
- **검색 기능**: 파일 목록의 실시간 검색
- **드래그 선택**: 드래그로 여러 파일 선택
- **일괄 작업**: 전체 선택 / 전체 해제 기능

### 🔍 서버 비교
- **서버 간 분석**: 다른 서버 간 파일 비교
- **해시 검증**: MD5 해시를 사용한 파일 무결성 확인
- **크기 비교**: 서버 간 크기 차이 식별
- **기준 서버**: 비교를 위한 기준 서버 설정
- **상세 파일 정보**: 서버별 파일 세부 정보 보기

### 📊 다운로드 관리
- **진행 상황 추적**: 속도 표시기가 있는 실시간 다운로드 진행 상황
- **동시 다운로드**: 더 빠른 완료를 위한 병렬 파일 다운로드
- **오류 처리**: 상세 로깅이 포함된 강력한 오류 처리
- **재개 기능**: 중단된 다운로드 계속하기

### 💾 데이터 지속성
- **요청 로깅**: 날짜 및 크기별 서버 요청 저장
- **설정 저장**: 향후 사용을 위한 서버 설정 저장
- **매니페스트 캐싱**: 더 빠른 로딩을 위한 파일 매니페스트 캐시

## 설치

### 사전 요구사항
- Python 3.7 이상
- tkinter (보통 Python과 함께 포함됨)
- 필요한 Python 패키지 (requirements.txt 참조)

### 설정
1. 저장소 클론:
```bash
git clone https://github.com/choco-lily/StellaSoraDownloader.git
cd StellaSoraDownloader
```

2. 필요한 패키지 설치:
```bash
pip install -r requirements.txt
```

3. 애플리케이션 실행:
```bash
python main.py
```

## 사용법

### 기본 워크플로우
1. **애플리케이션 실행**: `python main.py` 실행
2. **서버 선택**: 서버 선택 창에서 서버 선택
3. **파일 선택**: 체크박스 또는 드래그 선택을 사용하여 다운로드할 파일 선택
4. **다운로드 시작**: "Download Selected" 또는 "Download All" 클릭
5. **진행 상황 모니터링**: 진행 상황 창에서 다운로드 진행 상황 확인

### 고급 기능

#### 서버 비교
1. 서버 선택 창에서 "Compare Servers" 클릭
2. 검색 상자를 사용하여 파일 필터링
3. 드롭다운을 사용하여 기준 서버 설정
4. 선택한 서버와 비교하려면 "Apply Reference" 클릭
5. 파일을 더블클릭하여 서버별 상세 정보 보기

#### 파일 검색
- 모든 파일 목록의 검색 상자를 사용하여 파일 필터링
- 검색은 대소문자를 구분하지 않으며 부분 파일 경로와 일치
- 검색 결과는 필터링된 수와 전체 수를 표시

#### 드래그 선택
- 여러 파일을 선택하기 위해 클릭하고 드래그
- 체크된 파일에서 시작하면 범위의 모든 파일이 체크 해제됨
- 체크되지 않은 파일에서 시작하면 범위의 모든 파일이 체크됨

## 설정

### 서버 설정
애플리케이션은 `SERVERS` 딕셔너리에 정의된 여러 서버를 지원합니다:
- **KR 서버**: 한국 스텔라 소라 서버
- **EN 서버**: 영어 스텔라 소라 서버
- **JP 서버**: 일본어 스텔라 소라 서버
- **CN 서버**: 중국어 스텔라 소라 서버

### 파일 저장
- 다운로드된 파일은 선택한 디렉토리에 저장됩니다
- 서버 요청 데이터는 날짜 및 서버별로 자동 저장됩니다
- 설정 파일은 더 빠른 후속 로드를 위해 캐시됩니다

## 기술적 세부사항

### 아키텍처
- **GUI 프레임워크**: ttk(Themed Tkinter)가 포함된 tkinter
- **스레딩**: 서버 요청 및 다운로드를 위한 백그라운드 스레드
- **HTTP 클라이언트**: API 통신을 위한 requests 라이브러리
- **진행 상황 추적**: 다운로드 진행 상황 표시줄을 위한 tqdm

### 파일 구조
```
StellaSoraDownloader/
├── main.py                 # 메인 애플리케이션 파일
├── README.md              # 이 파일
├── requirements.txt       # Python 종속성
└── [서버 폴더]/           # 자동 생성된 서버 데이터 폴더
    └── [크기 폴더]/       # 파일 크기별로 구성된 폴더
        ├── config_*.json
        ├── config2_*.json
        └── manifest_*.json
```

### API 통합
- **인증**: 서버별 솔트가 포함된 사용자 정의 인증 헤더
- **설정 API**: 게임 설정 및 버전 정보 가져오기
- **매니페스트 API**: 해시 및 크기 정보가 포함된 파일 매니페스트 다운로드
- **파일 다운로드**: 서버 CDN에서 직접 파일 다운로드

## 오류 처리

애플리케이션에는 포괄적인 오류 처리가 포함되어 있습니다:
- **네트워크 오류**: 타임아웃 처리가 포함된 자동 재시도
- **파일 오류**: 파일 시스템 오류의 우아한 처리
- **사용자 중단**: Ctrl+C 중단의 깔끔한 처리
- **잘못된 데이터**: 서버 응답 및 파일 데이터의 검증
