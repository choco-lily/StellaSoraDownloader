# ステラソラ ダウンローダー

高度な比較と選択機能を備えた、複数のサーバーからステラソラゲームファイルをダウンロードするための包括的なGUIアプリケーションです。

## 機能

### 🌐 マルチサーバーサポート
- 複数のステラソラサーバー（KR、EN、JP、CN、TW）をサポート
- リアルタイムサーバー状態チェック
- サーバー固有のファイルサイズとハッシュ比較

### 📁 高度なファイル管理
- **ファイル選択**：チェックボックスを使用した特定ファイルのダウンロード選択
- **検索機能**：ファイルリストのリアルタイム検索
- **ドラッグ選択**：ドラッグによる複数ファイル選択
- **一括操作**：全選択/全解除機能

### 🔍 サーバー比較
- **クロスサーバー分析**：異なるサーバー間でのファイル比較
- **ハッシュ検証**：MD5ハッシュを使用したファイル整合性チェック
- **サイズ比較**：サーバー間のサイズ差異の識別
- **参照サーバー**：比較のための参照サーバー設定
- **詳細ファイル情報**：サーバー固有のファイル詳細表示

### 📊 ダウンロード管理
- **進捗追跡**：速度インジケーター付きのリアルタイムダウンロード進捗
- **並行ダウンロード**：より高速な完了のための並列ファイルダウンロード
- **エラーハンドリング**：詳細ログ付きの堅牢なエラーハンドリング
- **再開機能**：中断されたダウンロードの継続

### 💾 データ永続化
- **リクエストログ**：日付とサイズ別のサーバーリクエスト保存
- **設定ストレージ**：将来の使用のためのサーバー設定保存
- **マニフェストキャッシュ**：より高速な読み込みのためのファイルマニフェストキャッシュ

## インストール

### 前提条件
- Python 3.7以上
- tkinter（通常Pythonに含まれています）
- 必要なPythonパッケージ（requirements.txtを参照）

### セットアップ
1. リポジトリをクローン：
```bash
git clone https://github.com/choco-lily/StellaSoraDownloader.git
cd StellaSoraDownloader
```

2. 必要なパッケージをインストール：
```bash
pip install -r requirements.txt
```

3. アプリケーションを実行：
```bash
python main.py
```

## 使用方法

### 基本的なワークフロー
1. **アプリケーション起動**：`python main.py`を実行
2. **サーバー選択**：サーバー選択ウィンドウからサーバーを選択
3. **ファイル選択**：チェックボックスまたはドラッグ選択を使用してダウンロードするファイルを選択
4. **ダウンロード開始**：「Download Selected」または「Download All」をクリック
5. **進捗監視**：進捗ウィンドウでダウンロード進捗を確認

### 高度な機能

#### サーバー比較
1. サーバー選択ウィンドウで「Compare Servers」をクリック
2. 検索ボックスを使用してファイルをフィルタリング
3. ドロップダウンを使用して参照サーバーを設定
4. 「Apply Reference」をクリックして選択したサーバーと比較
5. ファイルをダブルクリックしてサーバー固有の詳細情報を表示

#### ファイル検索
- 任意のファイルリストの検索ボックスを使用してファイルをフィルタリング
- 検索は大文字小文字を区別せず、部分ファイルパスに一致
- 検索結果はフィルタリングされた数と総数を表示

#### ドラッグ選択
- クリックしてドラッグして複数のファイルを選択
- チェックされたファイルから開始すると、範囲内のすべてのファイルがチェック解除されます
- チェックされていないファイルから開始すると、範囲内のすべてのファイルがチェックされます

## 設定

### サーバー設定
アプリケーションは`SERVERS`辞書で定義された複数のサーバーをサポートします：
- **KRサーバー**：韓国語ステラソラサーバー
- **ENサーバー**：英語ステラソラサーバー
- **JPサーバー**：日本語ステラソラサーバー
- **CNサーバー**：中国語ステラソラサーバー

### ファイルストレージ
- ダウンロードされたファイルは選択したディレクトリに保存されます
- サーバーリクエストデータは日付とサーバー別に自動保存されます
- 設定ファイルはより高速な後続読み込みのためにキャッシュされます

## 技術的詳細

### アーキテクチャ
- **GUIフレームワーク**：ttk（Themed Tkinter）付きのtkinter
- **スレッド**：サーバーリクエストとダウンロードのためのバックグラウンドスレッド
- **HTTPクライアント**：API通信のためのrequestsライブラリ
- **進捗追跡**：ダウンロード進捗バーのためのtqdm

### ファイル構造
```
StellaSoraDownloader/
├── main.py                 # メインアプリケーションファイル
├── README.md              # このファイル
├── requirements.txt       # Python依存関係
└── [サーバーフォルダー]/  # 自動生成されたサーバーデータフォルダー
    └── [サイズフォルダー]/ # ファイルサイズ別に整理されたフォルダー
        ├── config_*.json
        ├── config2_*.json
        └── manifest_*.json
```

### API統合
- **認証**：サーバー固有のソルト付きのカスタム認証ヘッダー
- **設定API**：ゲーム設定とバージョン情報の取得
- **マニフェストAPI**：ハッシュとサイズ情報付きのファイルマニフェストのダウンロード
- **ファイルダウンロード**：サーバーCDNからの直接ファイルダウンロード

## エラーハンドリング

アプリケーションには包括的なエラーハンドリングが含まれています：
- **ネットワークエラー**：タイムアウト処理付きの自動再試行
